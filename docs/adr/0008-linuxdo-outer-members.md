# 0008 外层 `🐧 LinuxDo` 的成员

状态：已接受

## 背景

ADR 0007 确定外层为 select 分组，第一项固定为 `🐧 LinuxDo 自动`，其余成员待定。

关于直连：本机 DNS 把 linux.do 解析为 31.13.76.99（Facebook IP，受污染），但有用户反馈用 DoH 解析后可以不走代理访问。直连时 Cloudflare 看到的是用户自己的国内 IP，信誉通常较好；能否连通、速度如何取决于 Clash 的 DNS 配置和当地到 Cloudflare 的线路。

## 决策

`🐧 LinuxDo` 成员按顺序为：

1. `🐧 LinuxDo 自动`（默认）；
2. `🚀 手动选择`；
3. `DIRECT`。

## 备选方案

- **再加入 `🎯 纯净优选`、各地区分组、静态 / 家宽分组**：选项更多，但列表变长，这些出口都可以经 `🚀 手动选择` 选到。用户未采用。
- **不加 DIRECT**：避免误选后打不开，但失去直连这个可试选项。用户未采用。
- **列出所有单个节点**：列表过长。放弃。

## 后果

- 正面：选项少，`🚀 手动选择` 已能覆盖任意地区分组；DIRECT 供用户试验直连。
- 负面：选 DIRECT 后能否打开取决于本地 DNS 和线路，出问题需要用户自己切回。
- 跟进：如果直连实测可用，可考虑调整默认项（需新建 ADR）。
