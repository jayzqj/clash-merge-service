# 0009 内层 `🐧 LinuxDo 自动` 无成员时的处理

状态：已接受

## 背景

阈值调得很低，或评分接口长期故障导致没有分数时，`🐧 LinuxDo 自动` 可能没有任何节点达标。mihomo 的分组不能没有成员，否则 `mihomo -t` 校验失败，整份订阅无法发布。

## 决策

- 内层 `🐧 LinuxDo 自动` 照常生成并保留在外层 `🐧 LinuxDo` 第一项；
- 没有节点达标时，内层只放 `REJECT`（与 `🎯 纯净优选` 为空时一致）；
- 此时 linux.do 会打不开，由用户在外层手动切到 `🚀 手动选择` 或 `DIRECT`；
- 运行报告记录内层成员数（为 0 时可在管理页看到）。

## 备选方案

- **内层只放 `🚀 手动选择`**：无需操作即可继续访问，但用户选择自己处理。未采用。
- **退回全部已输出节点**：阈值静默失效，不显眼。放弃。

## 后果

- 正面：行为与 `🎯 纯净优选` 一致，分组结构固定不变，Clash Verge 记住的选择不会因分组增减而失效。
- 负面：无成员时 linux.do 直接不可用，需要用户发现并手动切换。
- 跟进：是否在企业微信通知里提示“linux.do 分组为空”，可后续再定。
