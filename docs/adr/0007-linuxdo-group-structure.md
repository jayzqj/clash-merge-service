# 0007 linux.do 分组结构：select 外层 + url-test 内层

状态：已接受。“两个分组都由代码生成”Superseded by 0011，改为 ini 定义、代码只填内层成员。

## 背景

ADR 0004 确定自动选择使用 url-test（容差 200ms）。自动选出的节点也可能被 Cloudflare 频繁验证或实际体验差，用户需要能临时手动指定出口。现有 `🤖 国外AI`、`📈 Bybit` 都是 select 分组，内含其他分组。

## 决策

生成两个分组（名称暂定）：

- **`🐧 LinuxDo`**：`select` 类型，ADR 0002 的分流规则指向它。第一项是 `🐧 LinuxDo 自动`，所以默认走自动选择；其余成员另行决策。
- **`🐧 LinuxDo 自动`**：`url-test` 类型，成员按 ADR 0006 预选，测速参数按 ADR 0003 / 0004。

两个分组都在转换后由代码生成（与 `🎯 纯净优选` 相同的方式），完整执行和重新应用规则都要生成。

## 备选方案

- **只有一个 url-test 分组**：最简单，但自动选的节点不好用时，只能在 url-test 分组里临时点选，下次测速可能又被切回。放弃。

## 后果

- 正面：默认自动，必要时可手动覆盖；与现有分组风格一致。
- 负面：多一个分组；Clash Verge 会记住 select 分组的手动选择，用户手动改过后不再自动走 `🐧 LinuxDo 自动`，需要自己切回。
- 跟进：外层成员列表见 ADR 0008；内层为空时的处理、分组在列表中的位置，另行决策。
