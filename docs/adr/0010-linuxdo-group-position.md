# 0010 linux.do 分组的名称与位置

状态：已接受。“由代码决定插入位置”Superseded by 0011，位置由 ini 书写顺序决定；名称仍有效。

## 背景

ADR 0007 暂定两个分组名，需要确定名称和在 `proxy-groups` 列表中的位置。`🎯 纯净优选` 当前插在 `🤖 国外AI` 之后（`app/groups.py`）。

## 决策

- 名称：外层 `🐧 LinuxDo`，内层 `🐧 LinuxDo 自动`；
- 位置：紧跟 `🎯 纯净优选` 之后，顺序为 `🎯 纯净优选`、`🐧 LinuxDo`、`🐧 LinuxDo 自动`；
- `🎯 纯净优选` 不存在时（理论上它总会生成），按它的插入规则退回：排在 `🤖 国外AI` 后，其次 `🚀 手动选择` 后，都不存在时追加到末尾；
- 重新生成时先移除旧条目再插入，保证位置随锚点变化（与 `add_low_purity_group` 的做法一致）；
- 两个分组不加入 `🚀 手动选择`、`🤖 国外AI` 等其他分组的成员列表。

## 备选方案

- **放在列表末尾**：不影响现有分组位置，但在 Clash Verge 里要往下翻才能找到。放弃。
- **放在最前面**：最显眼，但会挤下 `🚀 手动选择`，部分客户端把第一个分组当作主分组显示。放弃。

## 后果

- 正面：与 `🎯 纯净优选` 相邻，便于查找。
- 负面：实现时 linux.do 分组必须在 `🎯 纯净优选` 插入之后生成。
