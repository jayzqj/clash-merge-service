# Third-party components

This distribution bundles the unmodified Mihomo v1.19.15 Windows amd64-compatible binary, renamed to `clash-merge-mihomo.exe`. Mihomo is GPL-3.0 licensed. License text is included in `licenses/MIHOMO-LICENSE` and `_internal/vendor/MIHOMO-LICENSE`.

- Mihomo source and build instructions: https://github.com/MetaCubeX/mihomo/tree/v1.19.15
- Corresponding source archive: https://github.com/MetaCubeX/mihomo/archive/refs/tags/v1.19.15.tar.gz
- Geodata releases and their source/license information: https://github.com/MetaCubeX/meta-rules-dat
- pystray 0.19.5 (LGPL-3.0): https://github.com/moses-palmer/pystray/tree/v0.19.5
- Pillow 11.3.0 (HPND): https://github.com/python-pillow/Pillow/tree/11.3.0
- PyInstaller 6.16.0 (GPL with bootloader exception): https://github.com/pyinstaller/pyinstaller/tree/v6.16.0

Python packages and available license texts are inventoried in `licenses/versions.txt` and `licenses/`. Python runtime is included by PyInstaller. The application source and build script are available in the Clash Merge repository so users can rebuild with modified dependencies: https://github.com/jayzqj/clash-merge-service
